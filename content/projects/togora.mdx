Togora is a solo end-to-end project spanning backend services and cross-platform client architecture. The backend provides APIs supporting authentication, session management, and synchronised gameplay state across distributed clients, built with Node.js and GraphQL.

The client architecture supports media capture, upload, and asynchronous gameplay workflows across iOS and Android. The project is currently in active development.
