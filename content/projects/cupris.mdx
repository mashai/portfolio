Cupris brought me in at the prototype stage to unblock a hardware integration problem on TYM, their clinical-grade smartphone otoscope. The engineering team had stalled — the library they were using couldn't map to the microchip's buttons or lights, and they had no documentation to work from.

Using the Android NDK, I worked through the register map — identifying which addresses corresponded to each hardware component — and built a communication interface that exposed those as human-readable states to the mobile app. The integration was solved within a day. I spent the next writing documentation covering how to debug and communicate with the interface, leaving the team with a clear reference going forward.
